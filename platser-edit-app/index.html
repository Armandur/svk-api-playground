Sessions-cookie: laddar…

För att spara ändringar mot CMS:ets interna API behövs en CS_UserSessionId-cookie från en inloggad admin.svenskakyrkan.se-session. Hämta den med bookmarkleten nedan eller från DevTools.

  1. Logga in på admin.svenskakyrkan.se.
  2. Dra denna länk till bokmärkesraden: Kopiera CS_UserSessionId
  3. Klicka bokmärket på admin-fliken - cookie kopieras till urklipp.
  4. Klistra in nedan och spara:

Cookien är giltig 90 minuter inaktivitet. Den lagras i serverns RAM (inte på disk) tills du startar om eller rensar.
